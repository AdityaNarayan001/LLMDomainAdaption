# Dataset schema examples

One illustrative record per dataset type, generated by the **real builder code**
(`scripts/gen_examples.py`) so the schemas exactly match what the pipeline emits.
Regenerate with: `python scripts/gen_examples.py`.

| File | Produced by | Used in |
|---|---|---|
| `cpt_example.jsonl` | `build_cpt.apply_fim` | Stage 2 CPT (FIM, file-marked, document-masked) |
| `sft_instruction_example.jsonl` | `build_sft.assemble_instruction` | Stage 3 SFT (grounded instruction) |
| `sft_trajectory_example.jsonl` | `build_sft.to_chat` | Stage 3 SFT (rejection-sampled agent trajectory) |
| `rl_task_example.jsonl` | `build_rl.RLTask` | Stage 4 RL (issue→fix task + verifier) |

Key things to notice:
- **CPT** uses FIM sentinels (`<|fim_prefix|>` / `<|fim_suffix|>` / `<|fim_middle|>`) and a
  `// File:` marker; each record is one document (no cross-file attention bleed).
- **SFT** records carry a `loss_mask` aligned to `messages` — **only assistant turns
  train** (`true`); user/system/tool turns are masked (`false`).
- **RL** tasks carry the targeted `verify_cmd` (`cargo nextest run -p <crate>`) and a
  `single_crate` flag so the harness can verify cheaply.
